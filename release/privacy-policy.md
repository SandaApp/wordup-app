# WORDUP Privacy Policy

Effective Date: To be updated before release

WORDUP is designed to support Scripture reading, prayer, and spiritual growth while respecting user privacy.

## Data Stored on Device

WORDUP may store the following information locally on your device:

- App settings
- Reminder preferences
- Completed devotions
- Progress and streaks
- Saved verses
- Highlighted verses
- Private prayer requests
- Answered prayer status
- Badge progress

This information is stored locally on your device using device storage.

## Prayer Requests

Prayer requests are private by default and are stored locally on the user’s device in the MVP version of WORDUP.

WORDUP does not upload prayer requests to a server in this version.

## Internet Use

The current MVP is designed to function primarily offline after installation. Future versions may add optional cloud sync, community prayer, or account features. If those features are added, this privacy policy should be updated.

## Notifications

WORDUP may request notification permission to send daily Scripture and prayer reminders.

## Voice / Text-to-Speech

WORDUP uses the device’s text-to-speech system to read Scripture, prayers, and devotional content aloud.

## Data Sharing

WORDUP does not sell user data.

## Children and Families

WORDUP is family-friendly, but parents or guardians should guide children’s use of the app where appropriate.
